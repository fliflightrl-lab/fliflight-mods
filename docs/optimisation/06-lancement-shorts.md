## 1. Positionnement & identité

### Le principe directeur (à relire avant chaque vidéo)
1. **Les 3 premières secondes décident de tout** : hook visuel OU texte choc, jamais d'intro.
2. **Une vidéo = UNE idée** : un gag, une astuce, un avant/après. Pas de catalogue.
3. **Le pack se remarque, il ne s'annonce pas** : la démo doit être *visible*, le CTA en fin de vidéo + description.
4. **Format** : vertical 9:16, 15-45 s, sous-titres incrustés (80 % regardent sans le son).
5. **Régularité > perfection** : 3/semaine minimum, batchées.

## 2. Template de hook — les 3 premières secondes

La seule chose qui compte vraiment. Choisis UN de ces 6 modèles par vidéo :

| # | Modèle | Exemple |
|---|---|---|
| 1 | **Question piège** | « Pourquoi tu rates 90 % de tes coups ? » |
| 2 | **Affirmation choc** | « Ce réglage est interdit en tournoi. » (fake teaser → vraie astuce) |
| 3 | **Avant/Après immédiat** | split-screen 1 s : grotte sombre → minerais qui brillent |
| 4 | **Situation absurde** | « Je porte une citrouille et je vois tout. » |
| 5 | **Résultat final d'abord** | le clutch PvP réussi, puis « comment ? » |
| 6 | **Contradiction** | « Je joue SANS épée visible. Et je gagne. » |

Règle d'or : le spectateur doit **comprendre en 1 s** pourquoi il reste. Pas de logo, pas de « salut », pas de build-up.

## 6. Production — workflow batch

### Matériel minimum
- Minecraft Java + **OBS Studio** (gratuit) pour capturer en 1080p/60 fps.
- Montage : **CapCut** (gratuit, sous-titres auto + zooms rythmés intégrés).
- Voix : la tienne au micro, OU voix off IA (type ElevenLabs) si tu préfères — mais le gameplay
  réel et authentique reste obligatoire (jamais de scènes 100 % IA : tes tests l'ont prouvé).

### Session batch type (1×/mois)
1. Filme **2 h de gameplay** avec les packs équipés (fights, survie, bêtises).
2. Note les timestamps des moments intéressants pendant le montage.
3. Découpe en 12-15 clips de 15-45 s → 4 semaines de contenu.
4. Publie 3/semaine : Shorts (lundi/mercredi/vendredi) → crosspost TikTok + Reels le même jour.

### Checklist avant publication
- [ ] Sous-titres incrustés, lisibles, sans fautes
- [ ] Hook dans les 3 premières secondes (pas d'intro)
- [ ] CTA « gratuit, lien en bio » en fin
- [ ] Description avec lien CF + hashtags
- [ ] Cover/vignette simple si Shorts le propose
