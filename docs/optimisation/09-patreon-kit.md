## 1. Verdict honnête avant de cliquer

| | Patreon | Ko-fi (existant) | CurseForge Rewards (existant) |
|---|---|---|---|
| Type | Abonnement mensuel | Don ponctuel | Au download |
| Commission | **8 % + frais de paiement (~2,9 % + 0,35 $)** | 0 % (option 5 % tips) | 0 % |
| Effort récurrent | **Élevé** (1 actu/mois minimum, sinon churn) | Faible | Nul |
| Audience adaptée | Communauté active | Tous | Tous |

**Le vrai frein** : 86 000 downloads de *resource packs* ≠ 86 000 fans. Un pack de crosshair
se télécharge et s'oublie. Patreon ne marche que sur une **communauté** (Discord, serveur,
stream), pas sur un catalogue de packs.

→ Patreon vaut le coup **seulement si** les paliers donnent un accès anticipé *réel* et un
service récurrent (crosshair sur commande, configs PvP, clés OverBoost Pro, avantage
d'annuaire serveurs). C'est ce que fait la grille ci-dessous. Sinon : reste sur Ko-fi + CF.

**Fiscal (France)** : les revenus Patreon sont **imposables** (micro-BIC/BNC, déclaration
annuelle URSSAF/impôts même sans entreprise). Patreon collecte la TVA sur les abonnements à
ta place, mais ne déclare rien pour toi.

## 3. Grille des paliers

| # | Palier | Prix | Ce que le soutien reçoit |
|---|---|---|---|
| 1 | **Crosshair Club** | **3 €/mois** | Accès anticipé 48 h sur chaque pack/mod/sortie · vote sur le prochain pack · nom dans les crédits · rôle Patreon sur Discord |
| 2 | **PvP Pack** | **7 €/mois** | Tout le palier 1 + **1 crosshair sur-mesure par mois** (pseudo/couleurs/logo) + pack de configs PvP privées (sensitivity, keybinds, GUI, optifine/iris) + accès aux versions bêta du shader |
| 3 | **Team & Server** | **15 €/mois** | Tout le palier 2 + **bundle crosshair + épées + minerais aux couleurs de ta team** (1×/mois) + **boost d'annuaire top-serveurs.site** + 1 clé **OverBoost Pro** |
| 4 | **Founder** (limité à 10) | **30 €/mois** | Tout le palier 3 + **ton nom dans la description de tous les projets** + un pack conçu sur ton idée + accès à tous les fichiers sources (.py/.json, psd des textures) + appel Discord mensuel |

Notes de terrain :
- Le palier 1 doit être **≤ 3 €** : c'est le seul que la cible (14-20 ans, sans carte bancaire)
  peut payer. Prévoir l'option **PayPal** activée dans les réglages Patreon.
- Les paliers 2-4 servent surtout à faire monter le panier quand quelqu'un vient pour le
  crosshair — c'est le **service**, pas le pack, qui vend.
- Ne pas promettre de cadence de sortie (type « 2 packs/mois ») : promettre un **droit**
  (accès anticipé, vote, commande), jamais un volume.
